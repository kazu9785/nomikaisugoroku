飲みすごろく / 起動修正版

このフォルダだけで遊ぶためのファイルがそろっています。中に別のフォルダはありません。

【PCで試す】
ZIPを「すべて展開」し、このフォルダの index.html を開いてください。
初期のお題（またはこの場所で以前取得したお題）でゲームを開始できます。
ファイルを直接開いた場合は、端末間の設定共有・カード編集は利用できません。

【設定を共有して遊ぶ】
このフォルダの中身を全部、GitHubリポジトリの一番上へアップロードしてください。
以前の github-pages / server-source フォルダを作る必要はありません。
index.html / config.js / audio.js / questions.js / events.js / game.js / shared.js / catalog.js / style.css を同じ場所に置きます。
Settings → Pages → Deploy from a branch → main / (root) → Save。
公開後の https://ユーザー名.github.io/リポジトリ名/ から開いてください。
「共有設定を読み込み済み」と表示されれば、共通データベースのお題を利用しています。
通信失敗時もプレイできますが、最新の共有設定は取得されていません。
「共有データを更新」で再試行してください。編集の保存には接続とパスワード認証が必要です。

【更新】
同名ファイルをすべて上書きしてください。audio.js も必要です。
古い表示が残るときは Ctrl + F5 で再読み込みしてください。
データベースに保存したカード設定は、画面用ファイルの上書きでは消えません。

【音】
画面上部で音・BGM・音量を変更できます。最初のクリック/タップ後に再生されます。


【パーティー演出の追加】
・登録画面で各プレイヤーの駒と色を選べます。駒の小さい番号で同じアイコンも区別できます。
・サイコロはボタンを長押しし、離すと振れます。キーボードはSpaceまたはEnterです。ゲージの量で出目の確率は変わりません。
・カードが順番に配られ、選んだ1枚が中央でめくれます。
・各プレイヤーのゴールで紙吹雪とお祝い画面が出ます。「続ける」で進みます。
・杯数は各プレイヤーの＋／−で手動記録します。お題画面の「飲んだ杯数を記録」からも操作できます。自動では加算されません。
・隣の人を対象にする従来の飲むカードは名前ルーレットになります。3〜4人では引いた本人以外から抽選、2人ではもう1人が対象です。引いた後に自動で開始します。
・ルーレット結果の「飲んだ：＋1杯」で1回記録できます。下の手動カウンターと二重に記録しないように使ってください。
・杯数は今回のゲーム中の記録です。ページを再読み込みしたり、新しいゲームを開始したりすると0杯に戻ります。カードの共有データベースには保存しません。

【質問カード】
「質問はひとつだけ」は相手を選んだあと、72問からランダムで3問を表示します。1問を選んで会話を進めてください。候補の入れ替えは3回まで。同じ回の入れ替えでは質問が重複しません。
カード一覧で該当カードを開くと、質問の追加・編集・削除ができます。質問は最低3問必要です。候補を3回入れ替えるには12問以上必要です。
questions.js を含めて、全ファイルを上書きしてください。

【スマホの音】
音が出ない場合は、画面上部の「音を再開・テスト」をタップしてください。音量0の場合は35%に戻して確認音を再生します。BGMは別のONボタンで開始します。端末本体のメディア音量・消音設定・Bluetoothの出力先も確認してください。スマホ実機での音の聞こえ方は、端末設定によって変わります。

【好きな飲みゲーム】
選択肢は山手線ゲーム・ジャックポット・どすこい・わっしょい・二者択一・これ以外でやりたい飲みゲームの6つで固定です。山手線ゲームでは登録テーマからランダムな3候補と「好きなお題で遊ぶ」を表示します。自由なお題は入力しても、空欄のまま口頭で決めても遊べます。タイマーはありません。登録テーマを3件未満に編集した場合は、登録されている数だけ候補を表示します。
ほかの選択肢はゲーム名を表示し、みんなでゲームを進めてから終了ボタンで盤面に戻ります。これらの新しいゲームの判定や操作画面は含みません。

【スマホの操作画面】
・縦持ちではサイコロと次へボタンを画面下に固定。盤面はその上をスクロールして見られます。
・プレイヤー名と杯数は横にスワイプ。手番が変わるとその人の情報を表示します。
・音、音量、共有データの更新は「音・共有設定」を開いて操作します。
・タップ領域と入力文字を大きくしました。画面が低い場合は固定を解除してスクロールで操作できます。
