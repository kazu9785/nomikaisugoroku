# 飲みすごろく — アプリ内アクション版

2〜4人・端末1台で遊ぶネオンUIのすごろく。HTML / CSS / JavaScriptだけで動きます。

## 更新・起動
1. 既存プロジェクトを編集している場合は、先にフォルダーをコピーしてバックアップします。
2. ZIPを展開し、sugoroku-starter の中身を現在のフォルダーへ上書きします。
   例：D:\自作アプリ\sugoroku-starter
   index.html を D:\自作アプリ に直接置いている場合は、そこがコピー先です。
3. index.html / style.css / game.js / events.js を同じフォルダーに置きます。
4. ChromeやEdgeで index.html を開きます。表示が古ければ Ctrl + F5。

インストール・サーバー・npm・外部サービスは不要です。
VS Codeは「ファイル → フォルダーを開く」でプロジェクトを開き、保存後にブラウザーを更新します。
Eclipseは「Import → General → Existing Projects into Workspace」で取り込み、外部ブラウザーで実行できます。

## 基本ルール
- 全30マス。START・GOAL以外はすべてお題マス。
- マス内は番号・矢印・コマのみを表示。
- ぴったり到着したときだけゴール。余った目は折り返します。
  例：28から5が出ると29→30→29→28→27で停止。戻った先のお題が発生します。
- 次の番は再びゴール方向へ進みます。ゴール済みの人の手番は飛ばします。
- 6枚の裏向きカードから1枚を選択。残りは裏向きのままです。
- お題31種類（飲む系15・飲まない系16）。毎回の配布は3枚ずつです。
- 操作のあるカードは「このお題を始める」からプレイ。
- パス／Escでイベント終了。終了後に次の人へ交代します。
- 全員のゴールで終了。同じメンバーで再戦できます。
- 再読み込みでゲームはリセットされます。

## アプリ内でできるアクション
| お題 | 操作 |
|---|---|
| お絵描き・理想の休日 | キャンバスに指／マウスで描画。4色・3段階の太さ・1つ戻す・全消し。30秒で描画終了。早めに公開も可能 |
| 運命のコイントス | 相手の名前を選び、コインを投げる。表は相手、裏は自分。結果は1回だけ表示 |
| じゃんけん指名戦 | 相手を選び、交互に秘密で手を選択。勝敗を自動判定。あいこは再戦 |
| せーので数字 | 全員が順番に1〜3を秘密で選択し、一斉公開。対象者を自動判定 |
| 相手の好みを当てろ | 相手が好みを秘密で保存し、引いた人が予想。答え合わせを自動表示 |
| 山手線ゲーム | 20種類からランダムでテーマを1つ表示。タイマー・判定ボタンなし。遊び終わったら盤面に戻る |
| ジェスチャー・映画館 | 引いた人だけにランダムなお題を表示。お題を隠して20秒計測。時間切れかボタンで答え合わせ |
| ほめ言葉リレー | 話す人を順番に表示し、ボタンで交代 |
| 以心伝心チャレンジ | テーマ選択 → 交互に秘密の答えを入力 → 全員の回答を公開。最大3回。文字が一致すれば自動表示、意味が同じ場合は手動で一致を選べる |
| 好きな飲みゲームで勝負 | 10秒ストップ／金庫破り／じゃんけん／山手線／好み当てから選んで起動 |
| 相手指名系 | プレイヤーの名前をタップして対象を決定。「右隣」は実際の席に合わせて選択 |
| 10秒ストップ対決 | 全員が交互に挑戦し、結果をまとめて公開 |
| 金庫破り | 画面の数字を選び、範囲を狭めて勝負 |
| 相性二択チャレンジ | 相手を選び、3問に秘密で回答。一致数と回答を最後に表示 |

会話・ジェスチャー・口頭の答え合わせは参加者が行います。音声や身体の動きを自動認識する機能はありません。
お絵描きに紙・ペンは不要です。紙芝居のように画面を見せて、何の絵か口頭で当ててもらいます。
各カウントダウンは画面を離れる・パス・リセットで停止します。

## 誰のエピソード？
専用のイベントマスはなく、通常のお題カードに混ざっています。
引いた人が、10テーマからランダム表示される3候補のうち1つを選びます。

### 2人
引いた人が話を入力し「本当／作り話」を秘密で保存。端末を渡し、相手が予想して答え合わせ。

### 3〜4人
全員が同じテーマで話を入力し、ランダムな1件について全員が順番に予想。
書いた本人も操作に参加しますが、正解人数の集計からは除外します。全員の予想が終わってから答え合わせ。

各入力後・予想後は内容を隠す画面を挟みます。エピソードは120文字まで。1件の答え合わせで終了します。
入力内容は外部へ送信せず、ファイルにも保存しません。

## ファイル
- index.html：画面の構成
- style.css：ネオンUI、カード、キャンバス、スマホ向け配置
- game.js：サイコロ、移動、順位、ぴったりゴール
- events.js：お題・アプリ内アクション・エピソード
- .project：Eclipseへの取り込み用

お題は events.js の TOPICS、相性二択は PAIRS、エピソードのテーマは STORY_THEMES を編集します。

## 確認状況
JavaScriptの構文と、DOM／Canvasを模した環境で操作の流れを検証。
カード選択、コイントス、じゃんけん、数字選択、好み当て、タイマー満了・停止、描画の入力処理と操作ボタン、エピソードの人数別分岐、全員の完走、ゴール折り返しを確認しています。

## 山手線ゲームの更新
「食べ物編」の固定テーマを廃止し、食べ物・飲み物・都道府県・デートで行く場所など20テーマから1つ表示します。専用カードと「好きな飲みゲームで勝負」からの起動の両方に反映しています。テーマの変更は events.js の YAMANOTE_THEMES で行えます。
